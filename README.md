# Panel Contable

> Una plataforma centralizada para simplificar la gestión diaria de profesionales contables.

## Sobre el proyecto

**Panel Contable** es un proyecto en desarrollo creado con una idea sencilla: reunir en un único lugar las herramientas, alertas e información que un contador necesita consultar constantemente durante su jornada.

En lugar de depender de múltiples pestañas, planillas, recordatorios y sistemas separados, el panel busca convertirse en un **centro de operaciones** desde el que sea posible visualizar rápidamente qué requiere atención y actuar sobre ello.

La versión presentada actualmente es una **demo funcional**, desarrollada para mostrar el concepto, la interfaz y el potencial de las herramientas que formarán parte de la plataforma.

---

## El problema

La gestión contable cotidiana suele implicar trabajar simultáneamente con:

* Vencimientos impositivos.
* Clientes y sus obligaciones.
* Documentación pendiente.
* Tareas administrativas.
* Recordatorios.
* Información financiera.
* Diferentes sistemas y plataformas.
* Planillas utilizadas como soporte.
* Consultas que requieren revisar información constantemente.

El problema no siempre es la cantidad de trabajo, sino la **fragmentación de la información**.

Panel Contable busca solucionar precisamente eso:

> **Menos tiempo buscando información. Más tiempo gestionando el trabajo.**

---

## La propuesta

El objetivo del proyecto es construir una interfaz donde la información importante pueda visualizarse de forma inmediata.

### Un solo lugar

El panel está pensado para ofrecer una visión general del estudio desde una única pantalla.

Desde allí se podrán identificar rápidamente:

| Área           | Objetivo                                                         |
| -------------- | ---------------------------------------------------------------- |
| Dashboard      | Obtener una visión general del estado del estudio                |
| Vencimientos   | Detectar obligaciones próximas y atrasadas                       |
| Clientes       | Centralizar información y seguimiento                            |
| Tareas         | Organizar trabajo pendiente                                      |
| Notificaciones | Alertar sobre situaciones que requieren atención                 |
| Gestión        | Acceder rápidamente a las herramientas principales               |
| Información    | Consultar datos relevantes sin cambiar constantemente de sistema |

---

## La demo

Esta versión funciona como una **demostración del concepto de la plataforma**.

La interfaz busca representar cómo podría funcionar el producto final, mostrando una experiencia orientada a la productividad y a la consulta rápida de información.

### Principios de diseño

El panel está siendo diseñado alrededor de cuatro principios:

**Claridad**

La información importante debe ser visible sin necesidad de navegar por múltiples menús.

**Prioridad**

Los elementos que requieren atención deben destacarse sobre la información secundaria.

**Velocidad**

Las tareas frecuentes deben poder realizarse con la menor cantidad de pasos posible.

**Centralización**

La información relacionada debe permanecer dentro del mismo entorno de trabajo.

## Herramientas en desarrollo

La plataforma se encuentra en una etapa de desarrollo activo. Algunas de las herramientas que forman parte del concepto son:

### Dashboard

Una vista general del estudio que permite conocer rápidamente la situación actual.

Incluye indicadores, actividad reciente, próximos vencimientos y elementos que requieren atención.

### Sistema de vencimientos

Una sección dedicada al seguimiento de obligaciones.

La idea es poder diferenciar fácilmente entre:

* Vencimientos próximos.
* Vencimientos del día.
* Vencimientos atrasados.
* Obligaciones completadas.

### Gestión de clientes

Un espacio centralizado para consultar y administrar la información de cada cliente.

El objetivo es evitar tener que buscar información en diferentes lugares para realizar una tarea sencilla.

### Centro de notificaciones

Un sistema diseñado para convertir eventos importantes en avisos visibles.

Por ejemplo:

> Una obligación próxima a vencer.

> Un documento pendiente.

> Una tarea que requiere seguimiento.

> Una situación que necesita revisión.

### Gestión de tareas

Una herramienta orientada a organizar el trabajo diario.

Permitiría transformar una lista de obligaciones dispersas en un flujo de trabajo estructurado.

## Objetivo final

Panel Contable no busca simplemente crear otro software de gestión.

La intención es construir una herramienta que responda a una pregunta muy concreta:

> **¿Qué necesita saber y hacer un profesional contable en este momento?**

Y presentar esa información de la forma más rápida, clara y útil posible.

El proyecto parte de una idea simple:

**Todo lo importante debería estar a una sola pantalla de distancia.**

## Filosofía del proyecto

Panel Contable nace con una premisa:

> **La tecnología debería reducir la carga administrativa, no agregar otra capa de complejidad.**

Por eso, cada funcionalidad se plantea con una pregunta en mente:

**¿Esto hace que el trabajo sea más sencillo?**

Si la respuesta es sí, tiene lugar en el panel.

Si solamente agrega complejidad, probablemente no.
